## 💡 Идея проекта и решаемая проблема

В работе рекрутинговых агентств, HR-отделов и IT-аутстаффинговых компаний огромное количество времени уходит на рутинную **переупаковку резюме кандидатов** под единый корпоративный стандарт:
* Кандидаты присылают резюме в самых разнообразных форматах (выгрузки HeadHunter, многоколоночные Markdown-таблицы, сканированные PDF/OCR, текстовые файлы).
* Рекрутерам приходится вручную переносить опыт работы, чистить списки задач, формулировать краткое саммари (`pitch`), нормализовать периоды и верстать таблицы в Word.
* Ручной труд приводит к опечаткам, потере стека и артефактам верстки.

**HRCVHelper** автоматизирует эту рутину за счет гибридного движка на базе локальной LLM (**Ollama**) и универсального динамического экстрактора по принципу **Human-in-the-Loop**:
1. 🎯 **Экономия до 90% времени:** рутина по извлечению фактов, расчету стажа и верстке выполняется мгновенно.
2. 🛡️ **Защита от галлюцинаций:** HR-специалист видит распарсенный профиль в удобном веб-интерфейсе и может скорректировать любые поля перед генерацией документа.
3. 🔒 **100% соблюдение 152-ФЗ:** все вычисления выполняются строго в локальном контуре компании без отправки персональных данных во внешние облачные API.
4. ⚙️ **Отказоустойчивость:** гибридный парсер гарантирует извлечение данных даже при высокой нагрузке или недоступности GPU.

## ⚙️ Workflow обработки резюме

```text
[Исходный файл резюме] ──► [MDConvertor] ──► [LLMConvertor (Ollama/Dynamic)] ──► [Валидация HR (UI)] ──► [JSONToWord (docxtpl)] ──► [.docx в S3 / Скачивание]
```

1. **Загрузка:** HR-специалист загружает файл резюме (PDF, DOCX, TXT, MD) через веб-интерфейс или REST API.
2. **Конвертация в Markdown:** Сервис `MDConvertor` (`MarkItDown`) преобразует файл в структурированную текстовую разметку.
3. **Семантический парсинг:** `LLMConvertor` анализирует текст, определяет ФИО, контакты, целевую позицию, рассчитывает общий стаж, форматирует периоды работы по строгой маске, разделяет обязанности и достижения, находит стек технологий, образование и курсы.
4. **Интерактивная проверка (Validation):** Рекрутер верифицирует извлеченные данные в форме.
5. **Сборка `.docx` и сохранение:** `JSONToWord` генерирует презентабельный файл Word по корпоративному шаблону и сохраняет его в хранилище S3 (MinIO) с генерацией ссылки на скачивание.

## 🏗 Архитектура и микросервисы

Система построена на микросервисной архитектуре и оркестрируется через `docker-compose`:

| Сервис | Порт | Технологии | Назначение |
| :--- | :---: | :--- | :--- |
| **Frontend** | `8501` | Flutter Web, Nginx / Python HTTP | Клиентский веб-интерфейс для HR |
| **APIGateway** | `8000` | FastAPI, Pydantic | Единая точка входа, маршрутизация и оркестрация пайплайна |
| **AuthSystem** | `8001` | FastAPI, JWT | Аутентификация и контроль доступа |
| **MDConvertor** | `8002` | Python, MarkItDown | Конвертация документов любого формата в Markdown |
| **LLMConvertor** | `8003` | Python, Ollama, Regex Engine | Гибридный ИИ-парсер резюме в типизированный JSON |
| **JSONToWord** | `8004` | Python, docxtpl, python-docx | Генерация корпоративного документа `.docx` |
| **DBConnector** | `8005` | SQLAlchemy 2.0, Boto3 | Слой доступа к PostgreSQL и S3 (MinIO) |
| **PostgreSQL** | `5432` | PostgreSQL 16 Alpine | Хранение пользователей и метаданных резюме |
| **S3 (MinIO)** | `9000` / `9001` | MinIO | Локальное S3-совместимое объектное хранилище |
| **Ollama** | `11434` | Ollama | Локальный инференс больших языковых моделей |

## 🧠 Возможности и особенности парсера (LLMConvertor)

Парсер резюме спроектирован для работы с любыми нестандартными резюме на русском языке:

* **Гибридный режим работы:** Полноценный анализ локальной LLM с мгновенным динамическим фоллбэком при таймауте модели.
* **Строгая нормализация периодов:** Приведение дат к единой маске:
  `YYYY год MM месяц - YYYY год MM месяц / X ЛЕТ Y МЕСЯЦЕВ`.
* **Поддержка нестандартных версток:**
  - Корректная обработка многоколоночных таблиц и ячеек со свернутыми проектами (роль, стек, задачи, достижения в одной ячейке).
  - Склейка двухстрочных ФИО с переносом отчества (формат HeadHunter).
  - Распознавание заголовков вида `Имя - Должность`.
  - Нормализация всех видов Unicode-тире (`—`, `–`, `−`, `-`).
  - Фильтрация пустых шаблонных строк-заглушек (`Место работы / время`).
  - Разделение немаркированных задач и обязанностей по глаголам совершенного вида и пробелам.
  - Извлечение сертификатов и курсов (включая эмодзи `📚` и курсы внутри ячеек образования).
* **OpenXML-совместимость:** Форматирование списков для безопасной подстановки в шаблоны `docxtpl` без повреждения XML-структуры документов Word.

## ⚡ Запуск на Windows (BAT)

Для максимально простого запуска в корне проекта подготовлен интерактивный командный файл **`start.bat`**:

1. Дважды кликните по **`start.bat`** (или выполните в терминале):
   ```cmd
   start.bat
   ```
2. Выберите нужный режим:
   * **`[1]` Запуск в Docker Compose (Рекомендуется)** — собирает и запускает полный стек контейнеров в фоне.
   * **`[2]` Запуск в локальном режиме без Docker** — запускает локальный оркестратор `run_local.py` через виртуальное окружение Python.
   * **`[3]` Запуск тестов (pytest)** — запускает автоматизированный набор тестов.

Также доступны отдельные скрипты:
* `start_docker.bat` / `start_docker.ps1` — быстрый запуск контейнеров Docker Compose.
* `start_local.bat` / `start_local.ps1` — запуск локального режима без Docker.
* `run_tests.bat` / `run_tests.ps1` — запуск тестового набора.
