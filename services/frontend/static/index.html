            Шаг 3. Советы по форматированию в Microsoft Word
          

          

            

              
                format_bold Стилизация
              
              
Красьте теги в Word, делайте их жирными или курсивом — сгенерированный текст полностью унаследует это оформление.

            

            

              
                grid_view Таблицы и сетка
              
              
Теги можно вставлять внутрь ячеек таблиц без границ для создания аккуратной двухколоночной корпоративной верстки.

            

            

              
                visibility_off Условия {% if %}
              
              
Чтобы пустой блок не печатался, оборачивайте его: {% if pitch %}{{ pitch }}{% endif %}.
